# Olist Marketplace Analytics
Analyzed ~100k marketplace orders to find where revenue comes from
and whether late deliveries hurt customer reviews.

## Business questions
1. How do revenue and orders trend by month?
2. Which product categories and states earn the most?
3. How often are deliveries late, and does it lower review scores?
4. What share of customers buy again?

## Tools
Excel · Python (pandas) · SQL Server · Power BI

## Dataset
Brazilian E-Commerce Public Dataset by Olist (Kaggle)
